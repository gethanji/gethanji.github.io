에이전트 네이티브 지식베이스

에이전트는 이미 git에 삽니다.
이제 지식도 그곳에 삽니다.

한지는 팀이 아는 것을 순수 마크다운으로, 이미 소유한 저장소에 보관합니다. 사람을 위한 조용한 종이 앞면, 에이전트를 위한 작은 프로토콜, 그리고 파일 하나까지 내려가는 잠금장치입니다.

아이디어

종이는 그것이 쓰인 회의보다 오래 남습니다.

커밋됨 · 한 줄 diff, 나머지는 그대로

+ 그리고 내일 에이전트가 그대로 인용할 수 있습니다. claude · 제안함병합됨 ✓
그것을 만든 앱 없이는 읽을 수 없는 저장소. 안에 끼워 넣은 모델, 토큰으로 매겨지는 요금. 당신의 글과, 그것을 읽는 에이전트 사이의 벽.

그래서 우리는 그 반대를 만들었습니다.

01 · 앞면

종이처럼 읽힙니다.
프로처럼 커밋합니다.

따뜻한 종이, 긴 호흡의 읽기를 위한 세리프, 그리고 제자리에서 이뤄지는 편집. 업데이트를 누르면 뒤에서 정확히 하나의 깔끔한 커밋이 남습니다. 한 단어 수정은 한 줄 diff가 되어, 히스토리에 영원히 읽힙니다. 그리고 바이라인은 이 페이지를 마지막으로 확인한 시각을 말해 줍니다. 페이지는 당신이 보는 순간 동기화되니, 종이는 낡지 않습니다.

02 · 에이전트

에이전트가 제안합니다.
병합은 당신이 누릅니다.

코딩 에이전트는 MCP로 읽고, 프로처럼 기여합니다. 브랜치, diff, 그리고 당신의 결정. 그들의 이름은 히스토리에 남습니다. 일 년 뒤에도 git blame은 여전히 진실을 말해야 하니까요.

03 · 잠금

한 페이지 단위까지
잠급니다.

열림은 아래로 흐르고, 사람은 그 흐름을 뚫는 예외입니다. 두 사람이 공유하는 노트는 다른 모두에게 보이지 않습니다. 트리도, 검색도, 링크도 전부. 잠긴 페이지는 존재하지 않는 페이지와 똑같아 보입니다.

하나의 읽기 경로가 이를 강제합니다. 사람에게도, 에이전트에게도 똑같이.

04 · 여백

여백에서 이야기합니다.
기록에는 남기지 않고.

단어 하나를 골라 바로 그 지점에 코멘트하세요. 그 구절은 모든 독자에게 표시되고, 노트는 본문 옆 패널에 모입니다.

코멘트는 한지 자신의 저장소에 남고, 커밋도 내보내기도 되지 않습니다. 에이전트는 당신이 의도적으로 부여한 권한으로만 읽고, 기본값은 페이지 그 자체입니다.

한 단어 수정은 한 줄 diff

@remy

이름 바꾼 뒤에도 그대로인가요?

@owner

네 - 바이트 충실성은 유지됩니다.

05 · 장부

기계가 더 많이 씁니다.
누구의 손인지는 여전히 압니다.

여덟 주의 하루하루가 한 줄의 스트립에 놓입니다. 사람의 작업은 선 위에 먹으로, 에이전트의 작업은 선 아래 청자색으로. 커밋 자체에서 읽어냅니다. 공저자 트레일러도, 봇 계정도 포함해서요. 추측은 없고, 피드는 손과 종류로 걸러집니다.

검토할 것들은 정돈되어 도착합니다. 대기 중인 diff마다 에이전트가 남긴 셀프 리뷰, 변경량, 기다린 시간이 붙습니다. 그리고 hanji digest는 무엇이 바뀌었고 무엇이 당신을 기다리는지를 워크스페이스 안에 한 페이지로 적습니다. 산출물이 곧 알림이고, 조용한 날에는 아무것도 쓰지 않습니다.

여덟 주 · 누구의 손

사람, 선 위에이전트, 선 아래

my-claude

서문 손질 · +2 −1 · "다듬은 건 자신 있는데, 앵커가 아직 유효한지는 확인해 주세요."

06 · 무게

종이처럼 얇게.

오래 감을 말하는 은유만이 아니라, 측정된 무게에 관한 주장입니다. 읽기는 로컬 클론과 로컬 인덱스에서 나옵니다. 그 경로에 클라우드는 없고, 편집기는 편집을 누르기 전까지 아예 로드되지 않습니다.

~2ms에이전트가 페이지를 가져오는 시간
~14kB페이지 하나, 전송 용량
~2.5분3.5만 페이지 인덱싱
0번들된 LLM SDK

0이 핵심입니다. 이번 달 팀이 더 많이 썼다고 해서 한지의 비용이나 무게가 늘지 않습니다. 측정한 모든 수치 보기 →

07 · 원하는 방식으로

형태를 고르세요. 무엇을 고르든 몇 줄이면 됩니다.

혼자서, 로컬로

설치하고 열면 환영 화면이 나머지를 이어 줍니다. 공간의 이름, 비밀번호, 마크다운 폴더까지.

# 릴리스와 함께 공개됩니다:
git clone https://github.com/gethanji/hanji
pnpm install && pnpm dev:web
# → localhost:4100 greets you
빠른 시작 →

팀 전체, 테일넷에서

네트워크가 사람을 대신 로그인시키는 하나의 공유 인스턴스. 아무도 비밀번호를 입력하지 않습니다.

export HANJI_TAILSCALE_OWNER=you@github
next start -H 127.0.0.1 -p 4100
tailscale serve --bg 4100

08 · 의존이 아닌 것

에이전트를 위해 만들었습니다.
에이전트 없이도 돌아갑니다.

올해 대부분의 도구는 안에 모델을 넣고 계량기를 돌립니다. 한지는 그 반대 방향으로 에이전트 네이티브입니다. 당신의 에이전트는 반가운 손님일 뿐, 결코 의존 대상이 아닙니다.

설정에 API 키가 없고, 설정 화면에 모델 선택기가 없으며, "키를 직접 가져오라"는 요구도 없습니다. 토큰이 떨어져도 멈추는 것은 없습니다. 토큰이라는 것 자체가 없으니까요.

한지를 실행하는 데 필요한 전부
HANJI_DATA_DIR=~/.hanji
HANJI_SESSION_SECRET=•••
HANJI_OWNER_PASSWORD=•••
OPENAI_API_KEY
ANTHROPIC_API_KEY
MODEL_PROVIDER
이게 목록의 전부입니다. 그중 무엇도 모델과 통신하지 않습니다.

번들된 모델 없음. 크레딧 없음.
당신의 글과 에이전트 사이에 벽 없음.

언제든 떠나도 됩니다. 당신의 저장소에 있는 마크다운이고, 코드는 당신이 직접 돌릴 수 있습니다. AGPL, 무료입니다. 이어서 읽을 핸드북 자체가 한지로 내보낸 결과물입니다.
