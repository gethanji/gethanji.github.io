로컬에서. 팀과 함께. 웹으로. 당신의 방식으로.

네 가지 모두 첫 출시 범위에 포함됩니다.
01혼자, 로컬에서

한지를 열면 시작 화면이 안내합니다. 공간의 이름, 비밀번호, 마크다운 폴더만 정하면 됩니다.

# 출시와 함께 공개됩니다:
git clone https://github.com/gethanji/hanji
pnpm install && pnpm dev:web
5분 만에 시작하기
02팀과 함께, 테일넷에서

네트워크가 사용자를 알아보는 공유 인스턴스입니다. 누구도 비밀번호를 입력할 필요가 없습니다. 정해 둔 권한은 그대로 유지됩니다.

export HANJI_TAILSCALE_OWNER=you@github
next start -H 127.0.0.1 -p 4100
tailscale serve --bg 4100
테일넷에서 운영하기
03코딩 에이전트와 함께

MCP나 일반 HTTP로 허용된 범위만 읽습니다. curl을 쓰는 bash 스크립트도 에이전트가 될 수 있습니다. 편집은 검토할 수 있는 제안으로 도착합니다.

pnpm hanji token my-claude notes=read+propose
# 발급된 토큰으로 에이전트를 연결하세요.
에이전트에게 열쇠 건네기
04웹에 공개하기

모두에게 공개한 콘텐츠를 정적 웹사이트로 내보냅니다. 마크다운 사본과 llms.txt도 함께. 이 핸드북도 같은 방식으로 게시했습니다.

pnpm hanji rule handbook everyone-read
pnpm hanji export ./site
