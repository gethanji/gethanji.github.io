DÉPLOIEMENT

Lancer en local.
Partager à votre façon.

Local. Partagé. Publié. À vous de choisir.

Les quatre font partie de la première version.
01Vous seul, en local

Ouvrez Hanji et un écran d’accueil s’occupe de la mise en route : le nom que vous donnez à l’espace, votre mot de passe, votre dossier Markdown.

# public à la sortie :
git clone https://github.com/gethanji/hanji
pnpm install && pnpm dev:web
Démarrer en cinq minutes
02Votre équipe, sur un tailnet

Une instance partagée où le réseau authentifie les membres de l’équipe. Personne ne tape de mot de passe. Leurs droits restent exactement ceux que vous avez définis.

export HANJI_TAILSCALE_OWNER=you@github
next start -H 127.0.0.1 -p 4100
tailscale serve --bg 4100
Lancer sur votre tailnet
03Avec vos agents de code

Lectures limitées via MCP ou simple HTTP. Un script bash avec curl compte comme un agent. Les modifications arrivent sous forme de propositions : à vous de décider.

pnpm hanji token my-claude notes=read+propose
# Connectez votre agent avec le jeton renvoyé.
Donner une clé à votre agent
04Publié sur le web

Tout ce que vous avez ouvert à tous, sous forme de site statique. Un miroir Markdown et llms.txt sont fournis. Le manuel est publié ainsi.

pnpm hanji rule handbook everyone-read
pnpm hanji export ./site
En rendre une partie publique
